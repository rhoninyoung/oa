# T4.4 — E2E: Excel 级交互 + 总表新增/删除

## 目标

Playwright E2E：复制粘贴、Undo、Alt+Enter、冻结列；PM 总表新增/删除行。

## 前置

- T3.3、T3.7 完成

## 命中的用例 ID

- E2E-TBL-01、E2E-TBL-02
- E2E-MASTER-01、E2E-MASTER-02（[@p0]）

## 场景步骤

### Part A — Excel 级交互

1. GL 进入排期表
2. 选中 3×3 区域，Ctrl+C 复制
3. 选中 1×1 单元格，Ctrl+V 粘贴
4. 断言区域扩展为 3×3
5. Ctrl+Z 两次，断言完全回滚
6. 在备注列按 Alt+Enter → 单元格显示两行文本
7. 水平滚动 → 序号列始终可见（冻结）

### Part B — 总表新增/删除

8. PM 登录，进入总表 `/iterations/:id/master`
9. 点击「新增行」，选择负责人 U1，保存
10. 切换为 GL 登录，进入组排期表
11. 断言末尾出现新任务，负责人为 U1
12. `/dev/outbox` 页面检查有 2 条 notification
13. PM 删除该行 → 成功
14. PM 尝试删除 source=GROUP 行 → toast "系统同步行不可删除"，DB 数据不变
