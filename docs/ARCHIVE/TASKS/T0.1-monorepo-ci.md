# T0.1 — pnpm 单仓 + ESLint/Prettier + CI

## 目标

搭建完整的 monorepo 骨架，包含 lint 配置和 CI 流水线骨架。

## 前置

- 无

## 交付物

- `package.json`（root，pnpm workspaces）
- `pnpm-workspace.yaml`
- `.eslintrc.js`、`.prettierrc`
- `.github/workflows/ci.yml`

## 命中的用例 ID

- 无（脚手架本身无业务，不产生新用例）

## 实现要点

1. Root `package.json` 设置 `private: true`，` workspaces: ['packages/*', 'e2e', 'tools/*']`
2. 每个 package 的 `tsconfig.json` 继承 root 配置
3. CI 流程：

   ```yaml
   jobs:
     lint:     # pnpm lint
     dt:       # pnpm -r --filter=... test (DT only)
     ft:       # pnpm -r --filter=... test (FT, PR gate)
     e2e:      # pnpm --filter=e2e test (Playwright, PR + main)
   ```

4. 安装顺序约定：`shared` → `backend` → `frontend` → `e2e`

## 验收清单

- [ ] `pnpm install` 成功，无悬空依赖
- [ ] `pnpm lint` 全绿
- [ ] `pnpm -r test` 全绿（初版只有骨架测试）
- [ ] GitHub Actions CI 在 PR 上完整跑 lint → DT → FT → E2E 四阶段

## 不做什么

- 不配置发布（`pnpm publish`）
- 不写具体业务代码
