# T5.6 — PM 可编辑所有小组任务

## 目标

PM 在 GROUP 视图下可编辑所有小组的任务详情（名称、日期、进度、依赖等），不改变审批状态。

## 需求确认

- PM 可编辑**所有小组**的任务
- 编辑后**不改变审批状态**（自由编辑不限状态）
- PM 可编辑**全部字段**

## 修改文件

- `src/domain/permissions.js`
- `src/components/wbsTable.js`

## 变更内容

### `src/domain/permissions.js`

**`permit()` 函数** — 放行 PM 的 `edit` action：

```js
// 改前：
if (action === 'edit' || action === 'submit' || action === 'withdraw') {
  return { ok: false, code: 'PM_CANNOT_EDIT_DIRECTLY' };
}

// 改后：
if (action === 'edit') return { ok: true }; // PM 可编辑所有组的任务
if (action === 'submit' || action === 'withdraw') {
  return { ok: false, code: 'PM_CANNOT_SUBMIT' };
}
```

**`getFieldPermissions()` 函数** — PM 对 GROUP 任务返回 `readonlyFields: null`（全部可编辑）：

```js
// 改前：
if (isPM && task.source === 'GROUP') {
  return { ok: true, readonlyFields: new Set([...全部字段]) };
}
// GROUP tasks 块中也有重复的 PM 只读检查

// 改后：
if (task.source === 'GROUP') {
  if (isPM) {
    // PM 可以编辑所有 GROUP 任务
    return { ok: true, readonlyFields: null };
  }
  // GL 保持原有逻辑（仅自己组可编辑）
}
```

### `src/components/wbsTable.js`

**`_currentCanEdit` 变量** — 允许 PM 在任何组都可编辑：

```js
// 改前：
_currentCanEdit = (role === 'GROUP_LEADER' && schedule?.groupId === currentUser?.groupId);

// 改后：
_currentCanEdit = (role === 'GROUP_LEADER' && schedule?.groupId === currentUser?.groupId) || role === 'PROJECT_MANAGER';
```

**`startEdit()` — date 输入框类型**（附带修复）：

```js
// 改前：date 列也创建 type="text"
input.type = (col === 'durationDays' || col === 'progressPercent') ? 'number' : 'text';

// 改后：正确创建 type="date"
const isDateCol = col === 'startDate' || col === 'endDate';
input.type = col === 'durationDays' || col === 'progressPercent' ? 'number' : (isDateCol ? 'date' : 'text');
```

**blur 防护**（附带修复）：

在 `td.appendChild(input)` 后立即设置 `input.dataset.committing = '1'`，防止 capture-phase blur 在 input 就绪前触发 `applyCellEdit`。
