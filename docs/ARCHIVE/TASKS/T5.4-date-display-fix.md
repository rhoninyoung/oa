# T5.4 — 日期显示修复：ISO datetime → YYYY-MM-DD

## 问题

Prisma `DateTime` 字段序列化为 ISO 8601 格式（如 `"2026-05-04T00:00:00.000Z"`），导致前端 WBS 表格等位置显示的日期不正确。

## 根因

- `fetchInitData()` 从 `/api/init` 获取数据后未做日期格式归一化
- `mergeAPIData()` 对 API 响应中的日期字段未做归一化
- 各组件直接使用 `task.startDate` / `task.endDate` 渲染，未处理 ISO 格式

## 修复（3 层防御）

### 1. API 入口层 — `src/api/client.js`

`fetchInitData()` 调用后对 `iterations` 和 `tasks` 做日期归一化：

```js
function normalizeDate(dateVal) {
  if (!dateVal) return null;
  if (typeof dateVal === 'string') {
    return dateVal.includes('T') ? dateVal.slice(0, 10) : dateVal;
  }
  if (dateVal instanceof Date) {
    const y = dateVal.getFullYear();
    const m = String(dateVal.getMonth() + 1).padStart(2, '0');
    const d = String(dateVal.getDate()).padStart(2, '0');
    return `${y}-${m}-${d}`;
  }
  return dateVal;
}

function normalizeTask(task) {
  return { ...task, startDate: normalizeDate(task.startDate), endDate: normalizeDate(task.endDate) };
}

function normalizeIteration(iter) {
  return { ...iter, startDate: normalizeDate(iter.startDate), endDate: normalizeDate(iter.endDate) };
}

export async function fetchInitData(userId) {
  const data = await get(`/init?userId=${encodeURIComponent(userId)}`, userId);
  return {
    ...data,
    iterations: (data.iterations ?? []).map(normalizeIteration),
    tasks: (data.tasks ?? []).map(normalizeTask),
  };
}
```

### 2. Store 层 — `src/store.js`

`mergeAPIData()` 对合并的 tasks 做日期归一化（修复 `apiUpdateProgress` 等 API 响应的日期格式）：

```js
function normalizeDate(dateVal) { /* 同上 */ }
function normalizeTask(t) { return { ...t, startDate: normalizeDate(t.startDate), endDate: normalizeDate(t.endDate) }; }

export function mergeAPIData({ schedules, tasks }) {
  // ... schedules 处理不变 ...
  if (tasks) {
    const existing = new Map((_state?.tasks ?? []).map(t => [t.id, t]));
    for (const t of tasks) existing.set(t.id, normalizeTask(t));
    _state.tasks = [...existing.values()];
  }
  // ...
}
```

### 3. 显示层 — `src/components/wbsTable.js`

导出 `fmtDate()` 函数，确保所有日期渲染都使用 `YYYY-MM-DD` 格式：

```js
export function fmtDate(val) {
  if (!val) return '';
  if (typeof val === 'string') {
    return val.includes('T') ? val.slice(0, 10) : val;
  }
  if (val instanceof Date) {
    const y = val.getFullYear();
    const m = String(val.getMonth() + 1).padStart(2, '0');
    const d = String(val.getDate()).padStart(2, '0');
    return `${y}-${m}-${d}`;
  }
  return String(val);
}
```

WBS 表格渲染时使用 `fmtDate()`：
- 只读单元格：`${fmtDate(task.startDate) ?? ''}`
- HTML date input value：`value="${fmtDate(task.startDate)}"`

同时更新了：
- `src/main.js`（总表视图）：导入 `fmtDate`，渲染日期时使用
- `src/components/dashboardView.js`（首页仪表盘）：导入 `fmtDate`，`lagging-meta` 显示时使用
