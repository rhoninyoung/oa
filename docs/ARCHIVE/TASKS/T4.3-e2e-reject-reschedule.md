## 场景步骤

### Part A — reject 理由校验

1. GL 提交排期
2. PM 登录，点击「拒绝」
3. 断言「拒绝」按钮 disabled（reason 为空）
4. 输入 5 字 → 按钮仍 disabled（< 10 字拦截）
5. 输入 10 字 → 提交成功
6. GL 侧看到 REJECTED badge + reason 显示

### Part B — 双 context 冲突

7. GL 登录另一个 browser context，开始编辑任务（不提交）
8. PM 在另一 context 点击「重新排期」
9. PM 侧出现 `OVERWRITE_RISK` 弹窗
10. GL 侧出现 banner "PM 发起重新排期"
