# T0.3 — NestJS + Prisma + docker-compose Postgres + 基础 seed

## 目标

搭建 backend 骨架：NestJS 应用、Prisma ORM 连接到 docker-compose Postgres、基础 seed 数据、基础模块结构。

## 前置

- T0.1、T0.2 完成

## 交付物

- `docker-compose.yml`（PostgreSQL 16）
- `packages/backend/prisma/schema.prisma`
- `packages/backend/src/app.module.ts`
- `packages/backend/prisma/seed.ts`
- 基础 `SchedulesModule`、`TasksModule`、`ProjectsModule`（空 Controller/Service 占位）

## 命中的用例 ID

- 无（脚手架本身无业务，不产生新用例）

## 实现要点

1. `docker-compose.yml`：

   ```yaml
   services:
     postgres:
       image: postgres:16-alpine
       environment:
         POSTGRES_DB: oa_mvp
         POSTGRES_USER: oa
         POSTGRES_PASSWORD: oa_dev
       ports: ['5432:5432']
       volumes:
         - postgres_data:/var/lib/postgresql/data
   ```

2. `schema.prisma` 按 `docs/ARCHITECTURE.md` §2 数据模型实现（参考该文档中的完整 schema）
3. Prisma migration 初始化命令记录在 `docs/ARCHITECTURE.md`
4. Seed 数据：

   - 1 Project（"OA 平台"）
   - 1 Iteration（"2026-Q2 迭代"）
   - 2 Group（G1、G2）
   - 2 GroupLeader（U1 属 G1，U2 属 G2）
   - 1 ProjectManager（P1，无 groupId）

5. Backend 目录结构：

   ```
   src/
   ├── app.module.ts
   ├── main.ts
   ├── projects/     # ProjectsModule（空）
   ├── schedules/    # SchedulesModule（空）
   ├── tasks/        # TasksModule（空）
   ├── master/       # MasterModule（空）
   ├── outbox/       # OutboxModule（空）
   └── common/
       ├── guards/
       │   └── user-role.guard.ts   # 读取 X-User-Id header
       └── filters/
           └── http-exception.filter.ts
   ```

## 验收清单
