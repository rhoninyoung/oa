# T0.2 — `packages/shared` 类型 + Zod schema

## 目标

建立 shared 包，包含所有 TS 类型和 Zod 校验 schema，为 backend 和 frontend 提供唯一类型真源。

## 前置

- T0.1 完成

## 交付物

```
packages/shared/src/
├── index.ts
├── types.ts        # 所有 TS 类型
├── schema.ts       # Zod schema（从 types 派生）
├── stateMachine.ts # 状态机纯函数（T1.1 内容，提前暴露接口）
├── dependency.ts  # 依赖图纯函数（T1.2 内容）
├── calendar.ts    # 工作日历纯函数（T1.3 内容）
└── permissions.ts # 权限矩阵（T1.4 内容）
```

## 命中的用例 ID

- 无（纯脚手架，但后续 DT-SM-*/DT-DEP-*/DT-CAL-*/DT-PERM-* 依赖此包）

## 实现要点

1. 类型定义（`types.ts`）：

   ```typescript
   export type Role = 'GROUP_LEADER' | 'PROJECT_MANAGER'
   export type ScheduleStatus = 'PENDING' | 'REVIEWING' | 'APPROVED' | 'REJECTED'
   export type TaskSource = 'GROUP' | 'MASTER'
   export type TransitionAction = 'submit' | 'withdraw' | 'approve' | 'reject' | 'reschedule'

   export interface Task {
     id: string
     scheduleId: string
     orderIndex: number
     name: string
     ownerId: string | null
     startDate: string | null   // ISO date
     endDate: string | null
     durationDays: number | null
     dependencyTaskId: string | null
     source: TaskSource
   }

   export interface Schedule {
     id: string
     iterationId: string
     groupId: string
     status: ScheduleStatus
     version: number
     rejectReason: string | null
     tasks: Task[]
   }
   ```

2. Zod schema 逐个从 TS 类型派生，`schema.ts` 全部导出
3. 先不写业务逻辑实现（留空或 `throw new Error('TODO')`），仅保证类型正确

## 验收清单

- [ ] `packages/shared` 可被 `backend` 和 `frontend` 正常 import
- [ ] TypeScript 编译无错误（`pnpm -r build` 对 shared 单独跑）
- [ ] Zod schema 可对有效 payload 解析成功，对无效 payload 抛出错误（有基本校验用例）

## 不做什么

- 不实现状态机、依赖图等业务逻辑（留给 T1.1-T1.4）
