# T0.5 — Playwright 初始化 + 一条冒烟 E2E

## 目标

搭建 e2e 包骨架，安装 Playwright 并编写第一条冒烟测试（验证项目树渲染 + 角色切换）。

## 前置

- T0.1、T0.4 完成（frontend 可运行）

## 交付物

- `e2e/package.json`
- `e2e/playwright.config.ts`
- `e2e/tests/smoke.spec.ts`
- `e2e/fixtures/seed.ts`

## 命中的用例 ID

- E2E-NAV-01（冒烟版）

## 实现要点

1. `e2e/playwright.config.ts`：

   ```typescript
   export default defineConfig({
     testDir: './tests',
     timeout: 30_000,
     use: {
       baseURL: 'http://localhost:5173',
       trace: 'on-first-retry',
     },
     projects: [
       { name: 'chromium', use: { browserName: 'Chromium' } },
     ],
   })
   ```

2. `seed.ts` 复用 backend seed 数据，通过 `prisma seed` 初始化测试 DB
3. `smoke.spec.ts`：

   ```typescript
   test('nav: login as GL → see project tree', async ({ page }) => {
     await page.goto('/')
     // 角色默认 U1（GroupLeader in G1）
     await expect(page.getByText('OA 平台')).toBeVisible()
     await expect(page.getByText('2026-Q2 迭代')).toBeVisible()
   })
   ```

4. `beforeEach` 确保 DB 重置：`await exec('pnpm --filter backend prisma db push --force-reset && pnpm --filter backend prisma db seed')`
