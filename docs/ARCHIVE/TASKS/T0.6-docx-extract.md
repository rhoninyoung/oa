# T0.6 — `tools/docx-extract` Python 脚本

## 目标

从原 `.docx` 文件抽取图片，建立图片与文档章节的索引，供前端 UI 设计参考。

## 前置

- 无

## 交付物

```
tools/docx-extract/
├── extract.py          # 主脚本
├── test_extract.py    # pytest 测试（DT-DOCX-01, DT-DOCX-02）
└── README.md          # 使用说明
```

## 命中的用例 ID

- DT-DOCX-01、DT-DOCX-02

## 实现要点

1. 依赖：`python-docx`、`pyyaml`、`Pillow`（可选，用于生成缩略图）
2. `.docx` 本质是 zip 包，图片在 `word/media/` 目录下
3. `document.xml` 中的 `<w:drawing>` 标签按顺序引用图片，通过 `wp:docPr id` 或 `a:blip` 的 `r:embed` 关联
4. 通过遍历 `<w:p>` 段落记录最近一次 Heading 1/2，以建立「图片 → 章节」映射
5. 输出：
   - `docs/assets/ui-ref/img01.png` … `imgNN.png`
   - `docs/assets/ui-ref/index.yaml`：

     ```yaml
     - file: img01.png
       order: 1
       section_path: ["3. 小组排期功能逻辑", "3.2 交互触发规则"]
       caption_guess: "WBS表格快捷键示意图"
     ```

   - `docs/assets/ui-ref/README.md`：缩略图网格 + 章节标注

6. pytest 测试用 fixture `.docx` 放在 `tools/docx-extract/fixtures/`
