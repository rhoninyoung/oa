# T0.4 — Vite + React + Tailwind + 路由 + mock 登录

## 目标

搭建 frontend 骨架：Vite + React + TailwindCSS + React Router v6 + mock 登录（header `X-User-Id`）。

## 前置

- T0.1 完成

## 交付物

- `packages/frontend/vite.config.ts`
- `packages/frontend/src/main.tsx`
- `packages/frontend/src/App.tsx`（路由配置）
- 页面骨架：`/projects`、`/iterations/:id`、`/iterations/:id/master`
- Mock 登录：通过 URL param 或页面顶部角色切换器设置 `X-User-Id`，存于 `localStorage`
- `src/stores/userStore.ts`（Zustand，当前用户角色和 ID）

## 命中的用例 ID

- FT-AUTH-01、FT-AUTH-02（框架层即可验证拦截 401/403）

## 实现要点

1. 路由结构（React Router v6）：

   ```text
   /projects                          # 项目列表+侧边树
   /iterations/:iterationId          # 迭代详情（各组排期状态）
   /iterations/:iterationId/schedules/:groupId   # 组长排期表
   /iterations/:iterationId/master    # PM 总表
   ```

2. 角色切换器放在 layout 顶层，通过 `localStorage.setItem('x-user-id', userId)` 注入
3. `userStore` 提供 `currentUser: { id, name, role, groupId } | null`
4. Axios instance 拦截器自动注入 `X-User-Id` header
5. Tailwind 配置：`content: ['./index.html', './src/**/*.{ts,tsx}']]`

## 验收清单

- [ ] `pnpm --filter frontend dev` 启动无报错
- [ ] 切换角色后，刷新页面保持角色（localStorage）
- [ ] `GET /projects`（带 `X-User-Id`）返回数据；不带返回 401
- [ ] 路由跳转正常，侧边树展示项目/迭代层级

## 不做什么
