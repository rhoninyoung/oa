## 数据库操作

```bash
# 重置数据库并重新 seed
docker compose exec backend sh -c 'cd /app && pnpm --filter @oa-mvp/backend exec prisma migrate reset --force'
docker compose exec backend sh -c 'cd /app && pnpm --filter @oa-mvp/backend exec tsx prisma/seed.ts'
```

或直接 cp 新 seed.ts 后 seed：

```bash
docker exec <container_id> /bin/sh -c 'cat > /app/packages/backend/prisma/seed.ts' < packages/backend/prisma/seed.ts
docker exec <container_id> /bin/sh -c 'cd /app && pnpm --filter @oa-mvp/backend exec prisma migrate reset --force'
docker exec <container_id> /bin/sh -c 'cd /app && pnpm --filter @oa-mvp/backend exec tsx prisma/seed.ts'
```
